# 路线应急台 · 配送改派

- 行业：物流
- 技术栈：React、Vite、TypeScript
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

封路应急调度台：同一车次可整批转给有空位的司机，也可勾选部分订单拆单。每单带路线、送达时段与易碎标记；司机带装载上限、已装重量（由车上订单实时求和）与下一站时刻。改派逐单校验超吨、时段相撞、错过下一站与易碎缓冲箱，未通过的单据留在待处理区并注明原因；成功改派写入原车次、原因、新车次的记录，原车次装载立即减少。

代码按职责分层：`src/data.ts` 为资料与 localStorage 持久化（重开页面可追看），`src/logic.ts` 为纯计算（装载、时段、校验、改派执行），`src/App.tsx` 为页面。
