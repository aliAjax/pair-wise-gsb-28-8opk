# 路线应急台（封路应急改派调度）

- 行业：物流
- 技术栈：React、Vite、TypeScript、Ant Design、Zustand
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则验证：`npx tsx scripts/check-engine.mts`

## 2026-09-25 改派功能已完成

封路后调度员无需逐单改司机，在应急台上可把**同一车次整批**转给有空位的司机，也可**拆单改派**：

- 每单带路线、送达时段、易碎标记与重量；每位司机带载重上限、已装重量、空闲缓冲箱与下一站时刻。
- 目标车逐单试算，按序执行四条校验：
  1. **缓冲箱**：易碎件只能转给有空闲缓冲箱的司机（同批先装入的易碎件会占箱）；
  2. **超吨**：加装后总重不得超过载重上限；
  3. **时段相撞**：送达时段不得与目标车在装单重叠（端点相接不算撞）；
  4. **错过下一站**：送达截止必须晚于目标车下一站发车时刻。
- 通过的单立即转移并核减原车次装载；未通过的单连同原因留在**待处理区**，可换车再次试算。
- 每次改派写入流水：原车次、改派原因、新车次/司机、逐单结果；数据保存在 localStorage，重开页面仍可追看。

## 分层结构（资料 / 计算 / 页面分开维护）

```
src/emergency/
  types.ts                  # 领域模型与类型契约
  data.ts                   # 资料层：司机/车次/封路资料初始值
  engine.ts                 # 计算层：纯函数规则引擎（无 React、无存储）
  store.ts                  # 状态层：zustand + persist，改派与流水的唯一入口
  EmergencyBoard.tsx        # 页面：车次卡、待处理区、指标、封路管控
  components/ReassignModal  # 整批/拆单弹窗，目标车实时试算预览
  components/AuditPanel     # 改派流水（可展开逐单结果）
```

计算层是纯函数，后续接后端时只需把 `data.ts` 种子资料换成接口数据、`store.ts` 的动作换成异步请求，规则与页面无需改动。
